01 — What is Logistic Regression?

Logistic Regression is a supervised machine learning algorithm mainly used for classification. It estimates the probability that an input belongs to a particular class.

Imagine predicting whether a student will pass or fail based on their study hours. The model estimates the chance of passing and classifies the result using a chosen threshold.

02 — The sigmoid function

P = 1 / (1 + e−z)

The sigmoid function converts a model score into a value between 0 and 1, which can be interpreted as a predicted probability in a properly specified model.

z is the model's linear score. A probability closer to 1 indicates stronger support for the positive class; closer to 0 indicates stronger support for the negative class.

05 — Advantages & limitations

✨ Advantages

• Simple and interpretable
• Produces probabilities
• Useful for binary classification
• Efficient on many datasets

🔎 Limitations

• Assumes a linear relationship between predictors and log-odds
• Can struggle with complex patterns
• Needs suitable data preparation

07 — Conclusion

Logistic Regression is a foundational classification algorithm. By estimating probabilities and applying a decision threshold, it can help classify outcomes such as pass/fail or spam/not spam.

Remember: Logistic Regression predicts class probabilities; it does not guarantee that every prediction is correct.
